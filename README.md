# 🎲 D&D 5e Nexus Companion — Mobile First & Compêndio 2024

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FGui2761%2Fdnd5e-nexus)

Aplicação Web moderna, responsiva e mobile-first para jogadores e Mestres de **D&D 5e (SRD / Edição 2024)**.

---

## 🌟 Principais Recursos

### 1. 📱 Multiplayer Sem LocalStorage (Conexão entre Celulares)
- **QR Code Instantâneo**: Cada amigo aponta a câmera do celular para a tela e carrega sua ficha imediatamente.
- **Link Portátil Comprimido (LZ-String)**: Compartilhe a ficha inteira via WhatsApp ou Discord sem precisar de cadastro.
- **Sessão da Mesa**: Identificador de sala para sincronizar os amigos que jogam juntos em casa.
- **Exportação/Importação JSON**: Backup completo dos personagens em 1 clique.

### 2. 🎨 Temas Dinâmicos por Classe
A interface se transforma visualmente com cores e auras elementais:
- ⚔️ **Paladino**: Radiância Sagrada & Dourado Divino
- 🐉 **Feiticeiro Dracônico**: Escamas de Dragão & Chamas Rubras
- 🪓 **Bárbaro**: Fúria Carmesim & Sangue de Batalha
- 🔮 **Mago**: Mistério Arcano & Índigo Cósmico
- 🗡️ **Ladino**: Sombras Ônix & Lâmina Envenenada
- ✨ **Clérigo**: Luz Celestial & Prata
- 🌿 **Druida**: Círculo Silvestre & Musgo Ancestral
- 🎭 **Bardo**: Púrpura Real & Ouro
- 🥋 **Monge**: Harmonia do Ki & Âmbar Espiritual
- 🛡️ **Guerreiro**: Aço Temperado & Ferro Forjado
- 🏹 **Ranger**: Caçador da Floresta & Marrom Terra
- 👁️ **Bruxo**: Pacto de Outro Mundo & Fogo Abissal

### 3. 📚 Compêndio D&D 5e Integrado (Livro de Regras Completo)
- **Magias**: Níveis 0 a 9 com alcance, componentes, tempo, duração e dano/cura.
- **Armas**: Simples e marciais com propriedades (Acuidade, Versátil, etc.).
- **Armaduras**: Cálculo automático de CA conforme destreza e tipo (Leve, Média, Pesada).
- **Habilidades de Classe**: Destruição Divina, Fúria, Ataque Furtivo, Canalizar Divindade, Metamagia, etc.
- **Talentos e Condições**: Alerta, Combatente Montado, Envenenado, Paralisado, etc.
- **Autocompletar Inteligente**: Digite qualquer arma ou magia para preencher automaticamente as regras oficiais!

### 4. 🎲 Rolador de Dados Tátil Integrado
- Rolagens de d4, d6, d8, d10, d12, d20 e d100.
- Suporte a **Vantagem**, **Desvantagem** e **Modificador**.
- Destaque animado para **Crítico Natural (20)** e **Falha Crítica (1)**.
- Histórico completo de rolagens.

---

## 🚀 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
